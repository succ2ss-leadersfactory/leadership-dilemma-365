# 고객 회신 (시험용 가상 회신)

가상제약 인사팀 담당자 회신 요지입니다. 모두 지어낸 시험용 내용입니다.

1. 네, 업적(목표 달성) 60%와 역량 40%로 평가합니다.
2. 교육은 12월 둘째 주이고, 평가 면담 기간(12월 셋째~넷째 주) 바로 전입니다.
3. 가상 자료를 넣는 것은 괜찮습니다. 교육장 와이파이로 ChatGPT 접속도 됩니다.
4. 대부분 (나) 등급의 근거 설명 부분에서 나옵니다. 등급 자체에 대한 이의는 적은 편입니다.
5. 상대평가 배분 비율이 있습니다(S 10%, A 25%, B 50%, C 이하 15%).
8. 영업 약 60%, 연구·생산 약 30%, 지원 약 10%입니다.
9. 정한 비중은 없지만 실습이 많은 것을 원합니다.

나머지 질문은 내부 확인 뒤 다음 주에 답드리겠습니다.
