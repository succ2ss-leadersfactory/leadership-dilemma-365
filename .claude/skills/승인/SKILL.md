# /승인

받은 값: `$ARGUMENTS`

이 명령은 설계자가 채팅에서 직접 부른 경우에만 실행한다. 다른 명령이나 서브에이전트 안에서 대신 부르지 않는다.

1. 단계가 비어 있으면 `python3 tools/status.py show`로 상태를 보여 주고 어느 단계를 승인할지 묻는다.
2. 실행한다.

   ```
   python3 tools/status.py approve $0
   ```

3. "멈춤"이나 "이미 승인"이 나오면 출력을 그대로 보여 주고 끝낸다.
4. 승인되면 아래만 답한다.
   - 승인한 단계와 시각
   - 다음 할 일: 1 → `/단계 2`, 2 → (고객 회신이 오면 `03_고객회신.md`에 붙여 넣고 `/단계 2`로 회신 반영, 바로 구조로 가려면) `/단계 3-1`, 3-1 → `/단계 3-2 안 X <바꿀 점>`, 3-2 → `/내보내기`
   - 뒤 단계 중 "앞 단계 바뀜"이 있으면 그 단계 이름

참고: 2단계에서 회신 반영(02b)을 만들면 2단계는 다시 "초안"이 되므로 한 번 더 승인해야 3-1로 갈 수 있다. 2단계를 승인했을 때 3-1·3-2가 "앞 단계 바뀜"이면, 다음 할 일로 `/수정 3-1 02b 회신 반영 결과에 맞춰 바뀌는 곳만 고쳐 줘`(바뀔 곳이 없으면 `/승인 3-1`)를 알린다(CLAUDE.md "고객 회신 전에 3단계로 갈 때").
