# /새과정

받은 과정이름: `$ARGUMENTS`

1. 과정이름이 비어 있으면 만들지 말고 "과정이름을 붙여 주세요. 예: /새과정 가상제약_신임팀장"이라고만 답한다. 띄어쓰기가 있으면 밑줄(_)로 바꿔도 되는지 묻는다. 시험용은 `_시험/<이름>`처럼 쓴다.
2. 아래를 실행한다.

   ```
   python3 tools/status.py new "$ARGUMENTS"
   ```

3. "이미 있는 과정입니다"가 나오면 아무것도 덮어쓰지 말고 멈춘다. 그 과정으로 바꾸려면 `/과정 $ARGUMENTS`를 쓰면 된다고 알린다.
4. 만들었으면 아래만 짧게 답한다.
   - 만든 파일 두 개의 경로
   - 다음 할 일: `00_요청.md`의 빈칸(고객사, 업종, 대상, 인원, 교육 시간·형식, 요청 비중, AI 실습 환경, 주제와 고객이 말한 문제, 고객이 준 자료, 설계자 메모)을 채운 뒤 `/단계 1`
5. 설계자가 같은 메시지에 요청 내용을 함께 줬다면, 그 내용을 `00_요청.md`의 해당 칸에 설계자가 쓴 말 그대로 옮겨 적고(지어내지 않음, 없는 칸은 비워 둠) 무엇을 어느 칸에 넣었는지 알린다.
